Capstone · Solo project

Is memory loss only about age?

CDC health surveys · Python · scikit-learn · Tableau · Streamlit

I used to work with people diagnosed with dementia, so I wanted to understand memory loss better. I analysed two CDC health surveys: a phone survey of over 200,000 adults and a survey that tested people's memory.

  • Memory loss is almost as common at 45–64 (16.1%) as at 65+ (17.2%). Low income, depression and hearing problems matter as much as age.
  • Built a gradient boosting model that helps a health team decide who to contact first, tested on 52,043 people it had never seen.
  • Shared it as a Tableau dashboard and an 11-page Streamlit app with a budget planner.

Vanguard A/B test

Website redesign · Python · SciPy · Tableau

Did Vanguard's new online process help clients finish? We tested the redesign across 50,500 clients.

  • Completion rose from 65.6% to 69.3% (p < 0.001), but missed the 5% target that makes it worth the cost.
  • Recommended fixing the first step before a full rollout.
  • My part: cleaning and exploring 70,609 client records, and checking the test and control groups were comparable.

AI adoption in European companies

Data wrangling · Python · pandas · Eurostat API

How fast are European companies adopting AI, and what holds them back? We pulled seven Eurostat indicators through the API and merged them into one tidy table.

  • Average company AI adoption almost tripled, from 7.0% (2021) to 19.3% (2025).
  • The Netherlands ranks 6th in Europe (33.2%).
  • The top barrier is lack of expertise (about 70%), not cost.
